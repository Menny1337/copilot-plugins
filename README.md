# copilot-plugins

A public [GitHub Copilot CLI](https://github.com/github/copilot-cli) / Agency-compatible
plugin marketplace: a curated set of reusable agents and skills grouped into domain plugins
so you can load just what you need instead of polluting your global config.

> This repository is the canonical public source for the marketplace. Personal settings and
> credentials belong in each feature's documented local configuration, never in source.
> Plugin content is the source of truth; generated indexes (`CATALOG.md`, the catalog block
> below, and plugin README generated blocks) are produced by the scripts in `scripts/` — do
> not hand-edit them.

## Install

```bash
copilot plugin marketplace add Menny1337/copilot-plugins
copilot plugin install mnmstack@menny1337-plugins
```

`mnmstack` bundles the shared operational and customization skills. Install other
domain plugins from the catalog only when needed; Copilot does not auto-install
plugin dependencies.

### Switching from the three old plugins

This is a clean break: `mnmstack` replaces `core-skills`, `core-agents`, and `meta`.
A marketplace update may retain old installations; it does not uninstall them or
migrate your configuration. Review `copilot plugin list`, then use your CLI's
`copilot plugin uninstall <installed-name>` workflow to remove the three old
plugins and install `mnmstack` explicitly. Update old explicit `--agent` references,
profiles, aliases, and plugin paths manually. See the
[migration guide](docs/mnmstack-migration.md) for skill-first replacements and
preserved local configuration.

The four bundled assistant, Azure operations, researcher, and architect agents
are removed; their workflows now use skills in the current session. For example,
ask to capture a note with `assistant-capture`, get a briefing with `assistant-query`,
perform Azure CLI operations with `az`, research a report with `research-methodology`,
or design customization workflows with `agent-system-design`. This does not remove
support for user-defined agents elsewhere or prohibit appropriate delegation.

### Run mnmstack without installing it

Agency can load `mnmstack` for one session directly from GitHub. This does not
install it globally or make it available in other sessions:

```bash
agency copilot \
  --plugin github:Menny1337/copilot-plugins:plugins/mnmstack
```
