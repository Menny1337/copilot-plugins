# copilot-plugins

A public [GitHub Copilot CLI](https://github.com/github/copilot-cli) / Agency-compatible
plugin marketplace: a curated set of reusable agents and skills grouped into domain plugins
so you can load just what you need instead of polluting your global config.

> This repository is the canonical public source for the marketplace. Personal settings and
> credentials belong in each feature's documented local configuration, never in source.
> Plugin content is the source of truth; generated indexes (`CATALOG.md`, the catalog block
> below, and plugin README generated blocks) are produced by the scripts in `scripts/` — do
> not hand-edit them.

## Install

```bash
copilot plugin marketplace add Menny1337/copilot-plugins
copilot plugin install core-skills@menny1337-plugins
copilot plugin install <plugin>@menny1337-plugins
```

Install `core-skills` first. Copilot does not auto-install plugin dependencies, and
agents and domain plugins invoke shared skills from this bundle by name.
Replace `<plugin>` with another plugin name from the catalog below, such as `core-agents`.

### Run core skills and agents without installing them

Agency can load both core plugins for one session directly from GitHub. This does not
install them globally or make them available in other sessions:

```bash
agency copilot \
  --plugin github:Menny1337/copilot-plugins:plugins/core-skills \
  --plugin github:Menny1337/copilot-plugins:plugins/core-agents
```
