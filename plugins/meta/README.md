# `meta`

Meta-tooling for creating, auditing, packaging, scheduling, and continuously improving Copilot agents, skills, hooks, plugins, and workflows.

## Prerequisites

- The [GitHub Copilot CLI](https://github.com/github/copilot-cli) (or Agency) with this marketplace added (see **Install** below).

Authoring and audit skills need nothing beyond the Copilot CLI.

`scheduled-headless-copilot` needs the host operating system scheduler. `scheduled-skill-review` is macOS-specific and additionally uses launchd, Swift/SwiftBar, GitHub CLI, and Agency.

## Install

Add the marketplace once, then install this plugin:

```bash
copilot plugin marketplace add Menny1337/copilot-plugins
copilot plugin install meta@copilot-plugins
```

Update later with `copilot plugin update meta@copilot-plugins` (or `plugins-update` to refresh everything). See the [repository README](../../README.md) for per-session Agency profiles, aliases, and global-install options.
