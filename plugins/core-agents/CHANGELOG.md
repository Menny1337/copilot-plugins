# Changelog

All notable changes to the `core-agents` plugin are documented here.
Format follows [Keep a Changelog](https://keepachangelog.com/); this project adheres to [Semantic Versioning](https://semver.org/).

## [2.6.0] - 2026-09-17

_minor release._

- Added `github-session-sync`, including hidden session markers and a concurrency-safe
  local session-to-issue mapping.
- Added backend-neutral `agentStop` dispatch so configured GitHub sessions use the
  GitHub sync path while existing ADO behavior remains unchanged.
- Added shell and PowerShell launchers with strict target validation, opt-in controls,
  authentication checks, debounce, repository eligibility, and regression coverage.
