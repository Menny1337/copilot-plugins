# `core-agents`

Broadly-useful agents and supporting skills: assistant (notes, tasks, reminders, briefings, Teams messaging, optional ADO session sync), researcher (citation-driven reports), and azure-ops (Azure CLI and DevOps operations).

## Prerequisites

- The [GitHub Copilot CLI](https://github.com/github/copilot-cli) (or Agency) with this marketplace added (see **Install** below).

Most units need nothing beyond the Copilot CLI. Configure these optional integrations only when you use them:

| Unit | Requires |
| --- | --- |
| `azure-ops` | [Azure CLI](https://learn.microsoft.com/cli/azure/) (`az`), authenticated with `az login` |
| `m365-messaging` | Teams and M365 user MCP servers connected to the CLI |
| `ado-session-sync` | Azure CLI authenticated to the ADO organization, an ADO-backed assistant configuration, and explicit opt-in |

The advisory and `agentStop` hooks are included but disabled by default. Enable them only after configuring an ADO-backed assistant and explicitly opting in.

## Install

Add the marketplace once, then install this plugin:

```bash
copilot plugin marketplace add Menny1337/copilot-plugins
copilot plugin install core-agents@menny1337-plugins
```

Update later with `copilot plugin update core-agents@menny1337-plugins` (or `plugins-update` to refresh everything). See the [repository README](../../README.md) for per-session Agency profiles, aliases, and global-install options.
