# mnmstack

The default stack for personal tasks and messaging, Azure and DevOps,
research, browser automation, and Copilot customization. Skills run in the
current agent's context; the plugin ships no custom agents.

## Install

```bash
copilot plugin install mnmstack@menny1337-plugins
```

This replaces `core-skills`, `core-agents`, and `meta`. Read the
[migration instructions](../../docs/mnmstack-migration.md) before switching an existing installation. Installing
this plugin does not uninstall the old ones, rewrite scheduled tasks, or move
private configuration and memory.

## Use

Ask for the task directly. The current agent loads the relevant skill.
Personal notes and tasks use `assistant-capture` and `assistant-query`;
Teams uses `m365-messaging`; Azure uses `az`; cited research uses
`research-methodology`; GitHub issue and ADO ticket updates use `issue-updates`.
Customization authoring and review have their own
skills. A skill supplies guidance, not new permissions.

Independent reviewers and parallel workers remain available when a task needs
them. The removed plugin-specific agent names are no longer invocation targets.

## Startup hooks

The four existing startup hooks retain their order: memory-lint advisory,
tool detection, assistant command links, and session-sync advisory.
Session synchronization stays explicit by default; optional automation is not
enabled by this migration.

Assistant data/configuration and authorized architect-memory paths remain
unchanged. Private data is not bundled into this plugin.

## Prior versions

The original plugin changelogs are retained under `history/` for provenance.
New changes belong to this plugin's [changelog](CHANGELOG.md).

## Install

Add the marketplace once, then install this plugin:

```bash
copilot plugin marketplace add Menny1337/copilot-plugins
copilot plugin install mnmstack@menny1337-plugins
```

Update later with `copilot plugin update mnmstack@menny1337-plugins` (or `plugins-update` to refresh everything). See the [repository README](../../README.md) for per-session Agency profiles, aliases, and global-install options.
