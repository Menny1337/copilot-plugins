# default-tools.txt — curated list of dev-relevant CLI tools probed at sessionStart
# by detect-tools.{sh,ps1}. One tool name per line; blank lines and # comments are
# ignored. Only tools actually found on PATH are reported, so this list stays cheap.
# Keep it curated (tools an agent might realistically choose), NOT exhaustive — a
# full $PATH dump would bloat context. Extend per-machine via ~/.copilot/env-tools.txt.
#
# PATH executables ONLY — by design. Detection runs in a NON-interactive shell that
# does not source ~/.zshrc / ~/.bashrc, so tools that exist only as shell functions or
# aliases (e.g. nvm/corepack lazy-load shims for pnpm/yarn, oh-my-zsh git aliases) are
# intentionally NOT reported. This mirrors what an agent can actually invoke in its own
# non-interactive shell: advertising a function-only tool would just make the agent try
# commands that fail. To make such a tool detectable AND agent-usable, put a real binary
# or shim on PATH (e.g. `corepack enable` for pnpm/yarn) — do not add it here expecting
# the function form to be found.
