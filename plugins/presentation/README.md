# `presentation`

Presentation-designer agent and supporting skills for PPTX and HTML decks, structured presentation workflows, critique, and image generation.

## Prerequisites

- The [GitHub Copilot CLI](https://github.com/github/copilot-cli) (or Agency) with this marketplace added (see **Install** below).

Rendering and image workflows need extra tooling only when used:

| Skill | Requires |
| --- | --- |
| `pptx-creation` | Node.js, Playwright + Chromium/Chrome; LibreOffice only for PDF/image export |
| `nano-banana-cli` | Node.js, an image API key, ffmpeg, and ImageMagick |
| `presentation-critique` | Node.js; optionally the `markitdown` Python package for PPTX text extraction |

`html-presentation`, `presentation-workflow`, and `presentation-designer` need nothing beyond the Copilot CLI and a browser for HTML output.

`presentation-workflow` delegates its critique panel to the `multi-model-review` skill from `core-skills`. Install `core-skills` alongside this plugin; without it the workflow still runs, but Steps 7–8 lose their panel mechanics.

## Install

Add the marketplace once, then install this plugin:

```bash
copilot plugin marketplace add Menny1337/copilot-plugins
copilot plugin install presentation@menny1337-plugins
```

Update later with `copilot plugin update presentation@menny1337-plugins` (or `plugins-update` to refresh everything). See the [repository README](../../README.md) for per-session Agency profiles, aliases, and global-install options.
