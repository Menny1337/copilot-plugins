# Slide Design Principles

Professional presentation design rules for AI-generated slides.

## Typography

### Font Hierarchy

| Element | Size Range | Weight | Font |
|---------|-----------|--------|------|
| Main title (cover) | 40–48pt | Bold | Arial or Helvetica |
| Slide title | 32–36pt | Bold | Arial or Helvetica |
| Subtitle | 20–24pt | Regular or Light | Arial or Helvetica |
| Body text | 20–24pt | Regular | Arial or Helvetica |
| Bullet points | 18–22pt | Regular | Arial or Helvetica |
| Captions/footnotes | 14–16pt | Regular or Light | Arial or Helvetica |
| Data labels | 10–12pt | Regular | Arial or Helvetica |

**Hard minimum: 14pt** — nothing smaller than 14pt should appear on any slide.

### Font Rules

- Use **maximum 2 fonts** per presentation (1 is better)
- Stick to **web-safe fonts**: Arial, Helvetica, Georgia, Verdana, Tahoma, Trebuchet MS
- **Left-align** body text — center only titles, quotes, and single-line callouts
- **Line spacing**: 1.2–1.5× the font size
- **Paragraph spacing**: 6–12pt between paragraphs

## Color

### Palette Construction

Build a 5–6 color palette:

| Role | Count | Usage |
|------|-------|-------|
| Primary | 1 | Headers, key shapes, chart main color |
| Secondary | 1 | Subheadings, supporting elements |
| Accent | 1–2 | Highlights, CTAs, emphasis |
| Neutral dark | 1 | Body text, borders |
| Neutral light | 1 | Backgrounds, subtle fills |

### Contrast Rules

- **Dark on light**: Dark text (`#2C3E50` or darker) on white/light backgrounds
- **Light on dark**: White/light text on dark backgrounds (`#1a1a2e` or darker)
- **Never**: Medium-gray text on medium-gray background
- **Charts**: Each series must be visually distinct — avoid similar hues adjacent
- **Accessibility**: Ensure 4.5:1 contrast ratio minimum for body text

### Color Usage

- Be **consistent** — same color = same meaning throughout the deck
- Use **accent colors sparingly** — they lose impact when overused
- **Positive/negative**: Green for growth/positive, red for decline/negative (with context)
- **Avoid pure black** (`000000`) for text — use dark gray (`2C3E50`, `333333`) instead

## Layout

### Slide Dimensions

Standard: **16:9** (1280×720px / 10"×5.625")

### Grid and Margins

- **Margins**: Minimum 0.5" on all sides (0.75" preferred)
- **Safe area**: Keep all content within the inner 9"×4.5" rectangle
- **Alignment**: Use consistent x-positions across slides (creates visual rhythm)
- **Proximity**: Related elements close together, unrelated elements far apart

### Content Density

- **1 idea per slide** — the core rule
- **Maximum 5 bullet points** per slide
- **Maximum 25 words** per bullet point
- **Maximum 75 words** of body text per slide (excluding titles)
- If you need more text, **split into multiple slides**

### White Space

- White space is a design element, not wasted space
- **50% rule**: At least 50% of the slide should be empty/background
- Group content to one area — don't scatter elements across the entire slide
- Generous padding inside shapes and text boxes (0.2–0.3" minimum)

## Slide Types

### Title Slide
- Full-bleed background (gradient or image)
- Large title (40–48pt) centered
- Subtitle below (20–24pt)
- Minimal elements — let the title breathe

### Section Divider
- Bold background color or subtle gradient
- Section name large and centered (36–44pt)
- Optional brief tagline below (18–20pt)
- Visually distinct from content slides

### Content Slide (Text)
- Title at top (32–36pt)
- Body text or bullets below
- Optional accent shape or icon
- Left-aligned text, generous margins

### Data Slide (Chart/Table)
- Title as conclusion, not topic ("Revenue grew 23%", not "Revenue")
- Chart/table occupies 60–70% of slide area
- Source citation in small text at bottom (14pt)
- Minimal decoration — let the data speak

### Image Slide
- Full-bleed image OR image + text side-by-side
- For full-bleed: overlay text on semi-transparent dark band
- For split layout: image on one side (50%), text on other side
- Caption below or overlay

### Comparison Slide
- Two or three columns side by side
- Consistent formatting across columns
- Clear labels at top of each column
- Use color to distinguish (e.g., current vs. proposed)

### Quote Slide
- Large quotation marks or accent line
- Quote text 24–28pt, italic optional
- Attribution below in smaller text (16–18pt)
- Centered layout, generous white space

### Closing/CTA Slide
- Clear call to action or key takeaway
- Contact information or next steps
- Visual weight similar to title slide (bookend effect)

## Visual Hierarchy

Priority order (what the eye reads first):

1. **Largest text** (title)
2. **Boldest color** (accent elements)
3. **Images** (pull attention)
4. **Charts/data** (visual weight)
5. **Body text** (supporting detail)
6. **Fine print** (sources, footnotes)

Ensure slide hierarchy matches the priority of information:
- Most important → biggest/boldest
- Supporting → medium
- Contextual → smallest

## Common Anti-Patterns

| ❌ Don't | ✅ Do Instead |
|----------|--------------|
| Wall of text (100+ words) | Split into multiple slides |
| 8+ bullet points | Max 5, or use a table |
| Decorative clip art | Purposeful icons or photos |
| Every word in ALL CAPS | Caps for short headings only |
| Rainbow of colors | Stick to 5-6 color palette |
| Tiny text (< 14pt) | Enlarge or remove |
| Centered body paragraphs | Left-align body text |
| Busy backgrounds | Simple, high-contrast backgrounds |
| Animated transitions | Minimal or no transitions |
| Reading your slides aloud | Slides support the speaker, not replace |

## Presentation Flow

### Opening (Slides 1–3)
1. **Title slide** — compelling value proposition
2. **Hook** — provocative question, surprising stat, or "what if" scenario
3. **Agenda/objectives** — what the audience will learn or decide

### Body (Slides 4–N)
- Follow the chosen narrative spine consistently
- One idea per slide
- Every 3–5 slides, insert a **section divider** for pacing
- Mix slide types for visual variety (don't use 10 bullet slides in a row)

### Closing (Last 2–3 slides)
1. **Summary/key takeaways** — 3–5 bullets maximum
2. **Call to action** — what should the audience do next?
3. **Thank you / Q&A** — with contact info if needed

## Brand Consistency

- **Same palette** across all slides
- **Same fonts** across all slides (one for headings, one for body — or just one)
- **Same accent style** (if using colored shapes, use them consistently)
- **Consistent spacing** — same margins, same title position, same chart placement
- **Recurring elements** — logo, page numbers, divider lines in the same position
